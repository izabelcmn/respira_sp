# RESPIRA SP

Sistema inteligente de previsão da qualidade do ar na cidade de São Paulo
---


## Objetivo

Desenvolver um sistema capaz de:

- Monitorar a qualidade do ar em tempo real;
- Analisar variáveis meteorológicas associadas à poluição atmosférica;
- Prever concentrações futuras de poluentes (PM 2.5);
- Disponibilizar visualizações e agente inteligente para o usuário.
